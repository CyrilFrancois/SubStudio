# SubStudio: UX pass, clicks and guidance (2026-11-19)

**What this answers:** how many clicks Cyril's process takes in the UI and what a first-time user would not
understand, before and after the UX pass (Cyril, via the STEWARD, 2026-11-19: « everything accessible in a minimal
amount of clicks, while being explained how to use the UI/UX »). Spec: `user-process.md` (D-0002), target §7:
**≤ 3 clicks from opening the app to a running batch**.

**How it was measured:** a scripted walk with Playwright (headless Chrome, 1440×900) on the stub backend
(`SUBSTUDIO_API_STUB=1`, 4 synthetic videos in 2 folders). The script records each click on the common path, the
hint of every Queue stage, and the focus outline of the first 8 Tab stops. It also checked the first-run guide in a
real Chrome: it opens on the first visit, reopens from « How it works », and stays closed after a reload.
Screenshots: `ux-pass-2026-11-19/`.

## Clicks, step by step

| Step of Cyril's process | Before | After | What changed |
|---|---|---|---|
| Open the app, first time ever | 0 | 1 (« Got it ») | A guide explains the 4 steps and every cell state. It opens once, and « How it works » in the menu reopens it. |
| Languages (default OV · EN · FR, remembered) | 0 | 0 | Already in Settings; the Library link now reads « Languages: OV, EN, FR (change) ». |
| **Subtitle everything still to do** | **1 per folder + Start**: 2 for one folder, **3 for the 2-folder test library**, 23 for 22 loose videos | **1**: « Start all to do (N) » | With nothing ticked, Start takes every video still to do in the visible list (filters and search narrow it). Ticking boxes still starts just those. |
| Subtitle a few chosen videos | 1 per video + Start | same | Unchanged. |
| Watch progress | 1 (« Open the Queue » or the menu) | 1 | Each stage now has a hover hint saying what it does. |
| Check results per video × language | 0 (the Library shows them) | 0 | Each cell's reason is written under it, with no hover needed (« Empty file (0 bytes) », « checked when the video is started », « from English »). |
| Read and fix one subtitle | 1 (click a ✓ cell, or a language of a finished job) | 1 | A finished job now reads « Review: OV EN FR ». A ✓ cell's link names what it opens for screen readers. |
| Save the fix | 1 (Save) | 1 | Unchanged. |

**Common path (« subtitle these files in my usual languages »):** 1 click after the first visit, 2 on the very first
one, against the §7 target of ≤ 3. Before, the 22-episode Ghosts folder took 2 clicks: one folder checkbox and Start.

## What a newcomer would not have understood, and the fix

| Where | Not understood before | Now |
|---|---|---|
| Library cells | Why a cell is « missing », « unknown » or « not checked yet »: the reason was in a hover tooltip only. | One line under the cell, up to 2 lines, with the full text on hover. |
| « Original version » column | What OV means. | Header « Original version (spoken) », with a hover hint and an explanation in the guide. |
| Start | That a folder checkbox exists, and that nothing happens until something is ticked. | Start works with nothing ticked; the footer says what it will do and how to narrow it. |
| Queue stages | What Check / Download / Transcribe / Translate / Write do. | A hover hint per stage, for example « Check: the quality check judges the subtitles already in or next to the video; good ones are kept ». |
| Finished job | « OV EN FR » underlined, with nothing saying they open Review. | « Review: OV EN FR ». |
| Per-video overrides | When to use them, and that they are forgotten on reload. | A one-line hint, plus a hint for « Timing shift ». |
| An empty filter result | A dead end. | « Show all videos » button. |
| Keyboard | Focus was the browser's 1 px default outline, close to invisible on the dark theme. | A 2 px indigo outline on every focused control (`:focus-visible`), measured on the first 8 Tab stops. |

Already covered before this pass: a plain empty state on every screen (no videos, empty queue, Review without a
subtitle), state shown as icon and text and never colour alone, and the Settings hints for every option.

## Still open
- **« N lines left in English »** on a translated cell, with Review highlighting and filtering those lines: the
  frontend half waits for workspace-6e's `SUBSTUDIO_UNTRANSLATED` contract (`LanguageCoverage.untranslated`,
  `Cue.untranslated_from`). Review already flags and filters « not translated » lines.
- **« Old English track kept in the file, not used »** when an old track was rejected and SubStudio's own track is
  used: waits for workspace-6e's track reordering.
- A broken video (« unknown ») is included by « Start all to do » and fails with its reason. Skipping unreadable
  videos would save one failed job each; not done, because a Rescan after a repair should not need a different button.
- Hover hints (`title`) are not reachable by keyboard alone. The guide and the lines under the cells carry the same
  meaning in visible text.
